# BMW E87 120d – Hunter Green street build

Lille hjemmeside om bygningen af min BMW 120d E87 LCI (2009).
Hostes med GitHub Pages direkte fra `main`-branchen.

- `index.html` – selve siden
- `img/` og `vid/` – billeder og videoer (nummerplader er udskiftet)
- `manifest.webmanifest`, `sw.js`, ikoner – gør at siden kan lægges på iPhone-hjemmeskærmen og virker offline
